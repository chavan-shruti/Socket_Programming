# Socket_Programming
A basic JAVA TCP Client - Server communication project demonstrating socket programming , data transmission and networking classes using ServerSocket + Socket . 

# Technologies Used : 
1.Java 
2.Java Networking (java.net)
3.Java I/O (java.io)
4.TCP 

# Concepts implemented :
1. Socket and ServerSocket 
2. Client - Server architechture
3. TCP Connection establishment
4. BufferedReader and PrintStream
5. InputStreamReader
6. InputStream and OutStream
7. Reading input from keyboard
8. Sending and Receiving messages
9. While loop for continuous communication
10. Exception Handling
